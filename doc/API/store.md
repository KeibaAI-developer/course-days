# store.py

## `CourseDaysStore`

`course_days` テーブルの読み書きを行うクラスです。テーブルの定義は [params.md](./params.md) を参照してください。

### コンストラクタ

#### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `db_client` | `DbClient` | - | KeibaAIのDBへ接続するクライアント |
| `logger` | `logging.Logger \| None` | `None` | ロガー。省略時は `__name__` ベースのロガーを使用 |

---

### `setup()`

#### 概要

テーブルが無ければ作成します（`CREATE TABLE IF NOT EXISTS`）。

---

### `select()`

#### 概要

主キーのリストに対応する芝コース日数をまとめて読み出します。1レースの入力生成で45件程度の開催日が必要になるため、1件ずつ引かず1回のクエリで引きます。

主キーは4カラムの組であり、組のINでは絞り込めません。カラムごとのINで引き（要求した組の上位集合が返る）、要求した組だけを取り出して返します。

#### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `keys` | `list[CourseDaysKey]` | - | `(競馬場コード, 開催年, 開催月日, コース区分)` のリスト。重複は取り除かれる。空なら何もしない |

#### 返り値

主キー → 4カラムの値の辞書。**保存されているキーのみ**を含みます。

| キー | 型 | 説明 |
|---|---|---|
| `芝コース日目` | `int` | 使用開始から何日目か |
| `芝コース初日` | `str` | 使用開始日（YYYYMMDD） |
| `芝コース経過日数` | `int` | 使用開始日からの暦日数 + 1 |
| `芝コース週目` | `int` | 使用何週目か |

---

### `upsert()`

#### 概要

芝コース日数をまとめて保存します。既存のキーは更新します。

`updated_at` には現在日時（UTC）を明示的に入れます。`DEFAULT NOW()` は INSERT のときにしか効かず、`DbClient.upsert` が更新するのは渡したDataFrameに含まれるカラムだけであるためです。

#### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `values` | `dict[CourseDaysKey, dict[str, Any]]` | - | 主キー → 4カラムの値。空なら何もしない |
