# computer.py

## `CourseDaysComputer`

期間を指定して芝コース日数を計算し、`course_days` テーブルへ保存するクラスです。予測時・学習データ生成時に読むだけで済むよう、あらかじめ流しておきます。

### コンストラクタ

#### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `data_interface` | `DataInterface` | - | 開催スケジュールとレース基本情報の取得に使う |
| `db_client` | `DbClient` | - | `course_days` テーブルへ接続するクライアント |
| `logger` | `logging.Logger \| None` | `None` | ロガー。省略時は `__name__` ベースのロガーを使用 |

---

### `compute()`

#### 概要

指定期間の芝の開催日について芝コース日数を計算し保存します。

- 冒頭でテーブルを作成します（無ければ）
- **保存済みの開催日は計算し直しません。** 長い期間をまとめて流すことを想定しており、途中で止まっても再実行すれば続きから進みます
- 100件ごとに保存します。長時間の実行が途中で落ちてもそこまでの結果は残ります

#### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `start_date` | `str` | - | 開始日（YYYY-MM-DD形式） |
| `end_date` | `str` | - | 終了日（YYYY-MM-DD形式） |

#### 返り値

| 型 | 説明 |
|---|---|
| `int` | 保存した件数（開催日単位） |

#### 例外

| 例外 | 条件 |
|---|---|
| `LookbackLimitExceededError` | いずれかの開催日で過去開催日の遡及が上限（365日）を超えた場合 |

---

### `count_remaining()`

#### 概要

指定期間のうち未保存の開催日数を返します。保存も計算もしません。テーブルが無ければ作成します（保存済みかどうかを見るためテーブルを読むため）。

#### 引数

`compute()` と同じ。

#### 返り値

| 型 | 説明 |
|---|---|
| `int` | 未保存の開催日数 |

---

### `collect_targets()`

#### 概要

指定期間の芝の開催日をキーとして列挙します。開催スケジュールから開催日を取り出し、開催日ごとにコース区分を判定します。芝の開催が無い日は対象外です。

キーは競馬場コードの昇順に並び、同一競馬場内は開催スケジュールが返した順のままです。

#### 引数

`compute()` と同じ。

#### 返り値

| 型 | 説明 |
|---|---|
| `list[CourseDaysKey]` | `(競馬場コード, 開催年, 開催月日, コース区分)` のリスト |

---

## スクリプト

`scripts/compute_course_days.py` から実行できます。

```bash
# 未保存の開催日数を数える
python scripts/compute_course_days.py --start_date 2025-12-01 --end_date 2025-12-31 --count_only

# 計算して保存する
python scripts/compute_course_days.py --start_date 2015-01-01 --end_date 2025-12-31
```

| オプション | デフォルト値 | 説明 |
|---|---|---|
| `--start_date` | （必須） | 開始日（YYYY-MM-DD形式） |
| `--end_date` | （必須） | 終了日（YYYY-MM-DD形式） |
| `--provider` | `mykeibadb` | データ取得元 |
| `--count_only` | なし | 未保存の開催日数を数えるだけで保存しない |
